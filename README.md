# 📝 Student Notes Management System

> NoSQL Micro Project | AVPTI Computer Department | 6th Sem A

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express.js
- Database: MongoDB Atlas (Mongoose)

## ✨ Features
- Add Notes
- View All Notes
- Delete Notes

## 📁 Project Structure
student-notes-management-system/
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── backend/
    ├── server.js
    ├── package.json
    ├── .env.example
    └── models/
        └── Note.js

## 🚀 How to Run

### 1. Clone the project
git clone https://github.com/yashrajsinhbuilds/student-notes-management-system.git

### 2. Setup Backend
cd backend
npm install

### 3. Create .env file inside backend folder
MONGO_URI=your_mongodb_connection_string
PORT=5000

### 4. Run Backend
node server.js

### 5. Open Frontend
Open frontend/index.html in any browser
